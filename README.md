# بوت تحميل فيديوهات فيسبوك العامة

بوت Telegram بلغة Python يستقبل روابط الفيديو العامة من Facebook و`fb.watch`، يستخرج خيارات HD وSD، يعرض الصورة والعنوان، ثم يرسل الفيديو إذا كان تحت الحد أو يعطي رابط التحميل المباشر إذا كان أكبر.

> استخدمه فقط مع فيديوهات عامة تملك حق تنزيلها أو لديك إذن بتنزيلها. لا يحاول هذا المشروع فتح الفيديوهات الخاصة أو تجاوز تسجيل الدخول أو القيود الأمنية.

## المزايا

- يدعم `facebook.com/watch` و`/videos/` و`/reel/` و`/share/` و`fb.watch` والتحويلات.
- يستخدم `yt-dlp` لاستخراج الروابط العامة بصورة أوسع من الاعتماد على أسماء حقول HTML ثابتة.
- يرسل صورة مصغرة وعنواناً وأزرار HD/SD.
- يفحص الحجم قبل الإرسال ويحاول إرسال الملف إذا كان ضمن `MAX_UPLOAD_BYTES`، وإلا يرسل الرابط المباشر.
- حد افتراضي 10 طلبات لكل مستخدم بالدقيقة.
- كاش مؤقت داخل الذاكرة لمدة 15 دقيقة، مع تنظيف تلقائي.
- User-Agent وAccept-Language لمساعدة الصفحات العامة التي تحتاج ترويسات متصفح عادية.
- تسجيل أخطاء عبر logging.
- ffmpeg موجود داخل Docker للمهام التي تحتاجه مستقبلاً، لكن النسخة الحالية تختار صيغاً فيها صوت وفيديو قدر الإمكان.

## تشغيل محلي

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

افتح `.env` وضع توكن BotFather في `BOT_TOKEN`، ثم:

```bash
python bot.py
```

لا تضع التوكن في `bot.py` أو GitHub أو ملف README.

## Docker

```bash
docker build -t facebook-video-bot .
docker run --rm --env-file .env facebook-video-bot
```

## Railway / Render

1. ارفع الملفات إلى مستودع GitHub خاص.
2. أنشئ خدمة Worker أو خدمة Docker جديدة.
3. استخدم Dockerfile الموجود في المشروع.
4. أضف متغير البيئة `BOT_TOKEN` من لوحة الخدمة، ولا تضعه في الملفات.
5. شغّل الخدمة. هذا البوت يستخدم polling، لذلك يحتاج خدمة لا تنام. خطط Render المجانية التي تنام ليست مناسبة للتشغيل المستمر.

المتغيرات الاختيارية:

- `MAX_REQUESTS_PER_MINUTE=10`
- `CACHE_TTL_SECONDS=900`
- `MAX_UPLOAD_BYTES=51380224`
- `DOWNLOAD_DIR=./downloads`
- `LOG_LEVEL=INFO`
- `USER_AGENT=...`

## ملاحظات مهمة

- روابط Facebook المباشرة مؤقتة غالباً، لذلك الكاش قصير عمداً.
- إذا كان الفيديو خاصاً أو محذوفاً أو يتطلب تسجيل دخول، سيظهر للمستخدم تنبيه مناسب.
- حد الإرسال في Telegram قد يتغير حسب Bot API؛ أبقِ `MAX_UPLOAD_BYTES` أقل قليلاً من الحد المعلن.
- إذا أرسلت التوكن في محادثة أو سجلّ، اعمل له Revoke من BotFather وولّد واحداً جديداً، ثم حدّث متغير البيئة فقط.
